C# 是什麼？

  • C# 是 .NET 平台上最主要的語言；.NET 是免費、跨平台、開放原始碼的開發環境。
  • 用途很廣：桌面、手機、伺服器、雲端，甚至 IoT 裝置。
  • 編譯式語言：程式先編譯，再執行。
  • 強型別語言：每個變數在編譯時就有確定的型別。
寫程式碼 .cs→編譯 dotnet build→執行 dotnet run

第一個程式：Hello, World

最短寫法（一行就能跑）：

// This line prints "Hello, World"
Console.WriteLine("Hello, World");
  • Console：主控台（文字視窗）
  • WriteLine：輸出一行文字

傳統寫法（很多範例長這樣）：

using System;
namespace TourOfCsharp;

class Program
{
    static void Main()
    {
        // This line prints "Hello, World"
        Console.WriteLine("Hello, World");
    }
}

兩種寫法編譯結果相同；Main 是傳統寫法的程式進入點。

寫 C# 的三個規則

  1. 每一句指令以 分號 ; 結尾。
  2. 大小寫有差別：Console ≠ console。
  3. 用 大括號 { } 把程式碼包成區塊。

using System; 讓我們可以直接寫 Console，不必寫 System.Console。命名空間就像資料夾，用來整理程式。

變數與常用型別

變數＝有名字的盒子；型別＝盒子能裝什麼。

// 明確寫出型別
int count = 10;
double temperature = 36.6;

// 用 var 讓編譯器推斷型別
var name = "C#";

var：讓編譯器依值自動推斷型別。

型別用途
int整數
double有小數的數字
bool真 / 假
char單一字元
string文字

型別安全：錯誤在編譯時就被抓到

int a = 5;
int b = a + 2; // OK

bool test = true;

// Error. Operator '+' cannot be applied to operands of type 'int' and 'bool'.
// int c = a + test;
  • 整數加布林值沒有意義，編譯器直接報錯，程式不會帶著錯誤去執行。
  • C# 的 bool 不能轉成 int。
  • 變數宣告後不能改變型別。

if / else：二選一

void DisplayWeatherReport(double tempInCelsius)
{
    if (tempInCelsius < 20.0)
    {
        Console.WriteLine("Cold.");
    }
    else
    {
        Console.WriteLine("Perfect!");
    }
}

括號裡是布林運算式：結果是 true 就做上面，false 就做 else。

else if：檢查多個條件

int score = 75;
if (score >= 90)
{
    Console.WriteLine("優秀");
}
else if (score >= 60)
{
    Console.WriteLine("及格");
}
else
{
    Console.WriteLine("不及格");
}
  • 由上往下檢查，第一個成立的就執行，後面不再看。
  • 75 不滿足 ≥ 90，但滿足 ≥ 60 → 輸出「及格」。

想一想：score = 90 會輸出什麼？

switch：依值選擇路徑

int day = 6;
switch (day)
{
    case 6:
    case 7:
        Console.WriteLine("週末");
        break;
    default:
        Console.WriteLine("平日");
        break;
}
  • 由上而下比對，執行第一個符合的區段。
  • 都不符合 → 執行 default。
  • 一個區段可以有多個 case。
  • 每段必須以 break 結束，否則編譯錯誤。

Windows Forms 是什麼？

  • 用來建立 Windows 桌面應用程式的 UI 架構。
  • 提供控制項、繪圖、資料繫結與使用者輸入處理。
  • Visual Studio 有拖放式設計工具：把按鈕拖到視窗上就好，還有對齊輔助線。
拖放控制項→設定屬性→撰寫事件程式→執行

兩個核心名詞：表單與控制項

表單 Form

顯示資訊給使用者的視窗，例如 Form1。

控制項 Control

放在表單上、顯示資料或接受輸入的元件：按鈕、文字方塊、下拉清單……

使用者點滑鼠、按鍵盤會引發事件，程式再用程式碼回應 —— 這就是視窗程式「動起來」的方式。

動手做：建立第一個專案

  1. 安裝 Visual Studio 2026，勾選「.NET 桌面開發」。
  2. 建立新專案 → 搜尋 winforms → 語言選 C#。
  3. 選 Windows Forms App（不要選 .NET Framework 版）。
  4. 專案名稱 Names，Framework 選 .NET 10.0（LTS）→ 建立。
  5. 畫面出現 Form1 設計工具；從「檢視」打開工具箱與屬性視窗。

事件與事件處理常式

private void button1_Click(object sender, System.EventArgs e)
{

}
  • sender：誰引發了事件（例如被按的按鈕）。
  • e：事件附帶的資料（例如滑鼠位置）。
  • Windows Forms 是事件驅動：事件發生，就執行對應的處理常式。
  • 在屬性視窗選按鈕的 Click 事件並雙擊，Visual Studio 會自動產生處理常式。
  • 雙擊滑鼠其實也會引發 MouseDown、MouseUp、Click 等多個事件。

寫按鈕事件：把名字加入清單

private void btnAdd_Click(object sender, EventArgs e)
{
    if (!string.IsNullOrWhiteSpace(txtName.Text) && !lstNames.Items.Contains(txtName.Text))
        lstNames.Items.Add(txtName.Text);
}
  • ! 表示「不是」，&& 表示「而且」。
  • 文字方塊不是空白、而且清單裡還沒有這個名字 → 加入清單。
  • 按 F5 執行，輸入名字後按按鈕試試看。

表單的事件順序

啟動時

HandleCreated→BindingContextChanged→Load→VisibleChanged→Activated→Shown

關閉時

Closing→FormClosing→Closed→FormClosed→Deactivate

初學者先記住：Load 適合做初始化，FormClosing 可以在關閉前做確認。
