# 頁面重點（擷取紀錄）
- Windows Forms 是用來建立 Windows 桌面用戶端應用程式的 UI 架構，提供控制項、繪圖、資料繫結與使用者輸入處理。
- Visual Studio 提供拖放式的 Windows Forms 設計工具，並有格線與對齊輔助線。
- 表單（form）是向使用者顯示資訊的視窗；控制項（control）是顯示資料或接受輸入的個別 UI 元素，例如文字方塊、按鈕、下拉清單、選項按鈕。
- 使用者的動作（例如滑鼠點擊、按鍵）會引發事件，應用程式以程式碼處理。
- 版面配置輔助：FlowLayoutPanel、TableLayoutPanel、SplitContainer。
- 資料相關：DataGridView 以列與欄顯示表格資料；BindingSource 代表資料來源連線。
- 應用程式可存取本機硬體與檔案系統。
- Windows Forms for .NET 為開放原始碼（GitHub）；另有 .NET Framework 4 的實作，屬 Windows 作業系統元件。
